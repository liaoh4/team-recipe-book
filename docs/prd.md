# PRD: Team Recipe Book v1.0

- **Status:** Draft
- **Owner:** @liaoh4
- **Requirement:** #4
- **Discussion:** #3

## Problem
Team members share recipes in chat, and the recipes get lost quickly.
Nobody can find a recipe from last month.

## Goals
- Give the team one place to store recipes.
- Make it easy to submit a new recipe.
- Make it easy to browse recipes by category.

## Target users
Everyone on our team. Most of them know basic Markdown.

## Scope

### In scope
- Each recipe is a Markdown file in the repo.
- Team members submit recipes through pull requests.
- Each recipe includes: name, category, ingredients, steps, and author.
- An index page lists all recipes, grouped by category.

### Out of scope
- Photos
- Search
- User accounts

## Categories
- Breakfast
- Main
- Dessert
- Drinks

## Success metrics
- At least 20 recipes in the first month.
- At least 5 different team members submit a recipe.
- Anyone can find a recipe in under 30 seconds using the index page.

## Open questions
- Should we allow a recipe to belong to more than one category?
